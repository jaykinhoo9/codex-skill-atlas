# Skill Atlas · Codex 技能看板

装了一堆 Skill，却不太清楚 Codex 平时到底用了哪些。

Skill Atlas 把技能和会话放到一张地图上。哪些常用、每次会话读过哪些技能，打开就能看见。工作时，看板也会自动更新。

## 能做什么

- **看使用情况**：读取次数越多，小球越大。点开会话，就能看到它读过的技能。
- **找技能**：搜索名称，查看完整说明和关联会话，一键复制名称。
- **换颜色**：不同来源用不同颜色区分，也可以自己选颜色。
- **整理技能库**：筛出读取少于 3 次的技能，框选后批量删除。只删技能，不删会话；误删了可以在 30 天内从回收站恢复。

## 怎么安装

把这句话发给 Codex：

```text
帮我从 https://github.com/jaykinhoo9/codex-skill-atlas 安装 skills/codex-skill-atlas，装好后打开技能看板。
```

以后想看时，说一句 **“打开我的技能看板”** 就行。页面会在浏览器里打开。

Mac、Windows、Linux 都能用，需要 Python 3.9+。想自己安装的话，可以看[手动安装说明](docs/usage.md)。

## 关于数据

看板在你的电脑上运行，技能和会话数据不会上传。

这里的“使用次数”指能找到记录的技能文件读取次数。没有记录，不一定代表从没用过。
